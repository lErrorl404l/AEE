## 2. Change set

The change set is the `CHANGELOG.md` section `[1.1.1]`. The release fixed
the defects found in field testing. The named defects include:

- The four `compat_ace3` heat gates read CBA settings with a `0` fallback
  (issue #123, issue #154).
- Rain-on-optics droplets smeared across the view (issue #152).
- The Coriolis deflection read a guessed latitude (issue #154).
- The seasonal phase fed a degree-based `sin` in radians (issue #178).
- The ACE3 air temperature double-lapsed at altitude (issue #181).
