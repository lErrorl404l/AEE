# AEE kernel table

The kernel/driver split is Pillar 2 of the AEE framework. A **kernel** is a
pure function: it reads no engine state and writes none. A **driver** reads
engine state, calls the kernel, and writes the result. The kernel is the unit
of test and the unit of native port; only the driver touches the engine.

This table is generated by `tools/gen_kernel_table.py`. Do not edit it by hand.
Run the generator without `--check` to refresh it, and with `--check` to fail on
drift or on a kernel that contains an engine write.
